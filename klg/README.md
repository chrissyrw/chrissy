# Kigali Legends (KLG)

Kigali Legends is an open-world Kigali adventure/action game prototype.

## First prototype
- Browser-based 3D foundation using Three.js CDN
- Basic player movement
- Third-person camera foundation
- Kigali-inspired zones and landmarks as placeholders
- Architecture ready for player, world, missions, vehicles, NPCs, weather and economy systems

## Planned zones
Kimironko, Nyamirambo, Remera, Kacyiru, Nyarutarama.

## Future expansions
Volcanoes, Nyungwe and Lake Kivu.

## Run
Open `index.html` with a local/static server in Codespaces. No npm installation is required for this first prototype.
